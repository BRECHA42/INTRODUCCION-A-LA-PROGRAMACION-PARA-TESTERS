# Sistema de Usuarios

Proyecto realizado en Java utilizando IntelliJ IDEA y GitHub.

## Descripción

Sitio web http://cestore.ces.com.uy/adminces/.

---

## Funcionalidades

- Crear usuarios
- Modificar usuarios
- Eliminar usuarios
- Buscar usuarios
- Validación de datos
- Manejo de atributos básicos

---

## Datos requeridos

Cada usuario debe contener:

- Nombre
- Email
- Contraseña
- Edad
- ID de usuario

---

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub
